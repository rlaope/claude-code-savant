# Agent Manager - Configure Active Agents

$ARGUMENTS

## Overview

Manage which specialist agents are active in your Savant Chat sidebar. Core personas (Einstein, Shakespeare, Socrates, Steve Jobs) are always on by default.

## How to Use

### Web UI (Recommended)
Open Savant Chat (`npm run chat` or `/savant-chat`) and click the **Manage** button in the Dev or Biz section header to toggle agents on/off.

### Categories

**Core Dev (always on):**
- Einstein (The Professor) — conceptual explanations
- Shakespeare (The Bard) — code analysis
- Socrates (The Debugger) — error debugging
- Steve Jobs (The Visionary) — project direction

**Language Optimizers (toggle):**
- JVM Developer, Python Developer, Go Developer, Rust Developer
- Node.js Developer, Swift Developer, C/C++ Developer

**Infrastructure & DevOps (toggle):**
- AWS Architect, K8s Developer, IaC Developer
- Observability Engineer, CI/CD Engineer, Docker Developer

**System Design & SRE (toggle):**
- System Designer, Performance Detective, SRE Engineer

**Business Agents (toggle, SayNo always on as gateway):**
- Finance, Growth, Legal, Fashion, Logistics, F&B, SaaS
- E-commerce, Real Estate, Healthcare, Content, HR, Education, Travel

## Agent Selection Tips

Activate agents based on your project's tech stack:
- **Java/Spring project** → JVM Developer + Docker + K8s + CI/CD
- **Python ML project** → Python Developer + AWS + Docker
- **Node.js SaaS** → Node.js Developer + AWS + IaC + Observability + SaaS PM
- **Mobile app** → Swift Developer + AWS + CI/CD
- **Startup planning** → SayNo + Finance + Growth + SaaS PM
